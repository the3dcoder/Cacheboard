Settings

Home Assistant connection

Shared by every Home Assistant card, so you enter it once. Everything else on this dashboard works without it.

Add this page's origin under http: cors_allowed_origins in configuration.yaml and restart HA. Serving this file from HA's own /config/www folder skips that entirely, since it's then same-origin.

Backend companion (optional)

Only needed for things a browser can't do on its own: OpenAI API usage (which blocks browser calls outright) and keeping OAuth tokens alive. Leave blank and everything else works exactly as it does now. Setup is in server/.

Cards

A fresh install ships example cards so the dashboard isn't an empty page. Clear them once you're ready to add your own — or restore them if you want the tour back.
